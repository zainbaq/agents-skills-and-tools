# Archive

Everything in this folder is kept for reference only. It is **not installed** by the marketplace and **not maintained**.

## What is here

| Path | Contents |
| --- | --- |
| `skills/` | 22 general-purpose skills, one `SKILL.md` each. |
| `agents/` | 11 agents, three files each: `<name>.md`, `prompt.yml`, and `SKILL.md`. |

The files are unchanged from when they lived at the top level of this repository. Their git history is preserved.

## Why it was archived

This repository now ships pods: small groups of skills that serve one specific job. A general-purpose collection of unrelated skills is not a pod, so these no longer ship. See the [main README](../README.md).

## A note on `agents/*/SKILL.md`

Each archived agent folder contains a file named `SKILL.md`. Despite the name, it is human-readable documentation for that agent, not a loadable skill. It is left as it was.
